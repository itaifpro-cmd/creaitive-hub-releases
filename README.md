# CreAItive Hub – Downloads

Claude Code und Codex direkt in den Adobe-Creative-Cloud-Apps. Hier liegen nur die fertigen Panels;
installierte Panels holen sich Updates von selbst.

| App | Download | Installation |
| --- | --- | --- |
| Premiere Pro | [creaitive-hub-premiere.zxp](https://github.com/itaifpro-cmd/creaitive-hub-releases/releases/latest/download/creaitive-hub-premiere.zxp) | mit einem ZXP-Installer installieren, Premiere neu starten, *Fenster > Erweiterungen > CreAItive Hub* |
| Photoshop | [creaitive-hub-photoshop.ccx](https://github.com/itaifpro-cmd/creaitive-hub-releases/releases/latest/download/creaitive-hub-photoshop.ccx) | Doppelklick (Creative Cloud installiert es), Photoshop neu starten, *Plugins > CreAItive Hub* |

Die Links zeigen immer auf das neueste [Release](https://github.com/itaifpro-cmd/creaitive-hub-releases/releases/latest):
Es enthält alle Panels in ihrer aktuellen Version. Für die Nutzung ist ein Lizenzschlüssel nötig.

Zu jeder Datei gibt es eine `.sha256` mit ihrer Prüfsumme. Die Panels prüfen damit, dass ein Update vollständig
und unverändert heruntergeladen wurde.

`revoked.json` ist die Liste gesperrter Lizenzschlüssel (nur Ids).
