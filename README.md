# CreAItive Hub – Downloads

Claude Code und Codex direkt in den Adobe-Creative-Cloud-Apps. Hier liegen nur die fertigen Panels;
installierte Panels holen sich Updates von selbst.

| App | Datei |
| --- | --- |
| Premiere Pro | [creaitive-hub-premiere.zxp](https://github.com/itaifpro-cmd/creaitive-hub-releases/releases) |

Installation: die `.zxp` der App aus dem neuesten Release herunterladen und mit einem ZXP-Installer
installieren, dann die App neu starten und *Fenster > Erweiterungen > CreAItive Hub* öffnen.
Für die Nutzung ist ein Lizenzschlüssel nötig.

`revoked.json` ist die Liste gesperrter Lizenzschlüssel (nur Ids).
